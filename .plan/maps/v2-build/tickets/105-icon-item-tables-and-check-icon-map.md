# Icon item ID tables and `check-icon-map`

## What to build

[`/icons` route and cache](./086-icons-route-and-cache.md) ships `ITEM_SLUGS` empty, so every item icon request answers 404, and Gen 1-2 species answer 404 until their dex tables exist. Fill `ITEM_SLUGS` per art version from PokeAPI `item_game_indices`, add the `check-icon-map` HEAD script that checks every mapped slug resolves upstream, and add the Gen 1-2 species dex tables. Read the 086 report and `docs/icon-packs.md` first. Generated tables are checked in, and the generator run is stable.

## Acceptance criteria

- Item requests resolve for Emerald, FireRed and LeafGreen items that PokeAPI has art for, and the rest still answer 404.
- `check-icon-map` reports every mapped slug that doesn't resolve, and CI doesn't call the network unless a job opts in.
- Gen 1-2 species requests resolve once their reference data is present.
- No third-party icon files are committed.

## Answer

Item and Gen 1-2 species art now resolve. `server/src/icons/data/icon-maps.json` holds the Gen 1 and Gen 2 dex tables and the item ID to slug table for each art version. It is generated by `bun run generate:icon-maps` from PokeAPI's CSV data at a pinned commit, a rerun gives the same file, and a table lists only slugs with art at the pinned sprites SHA (130 Gen 1, 203 Gen 2, 308 Gen 3). Emerald, FireRed and LeafGreen items resolve, and every other ID still answers 404. Gen 1-2 species use the icon-local dex tables, so they resolve without waiting for their reference data. `bun run check-icon-map` sends a HEAD request for each of 5058 mapped upstream paths, retries, rechecks failures one at a time and exits 1 on any miss. It is not in `bun test` or a workflow, so CI stays offline.

At the pinned SHA two Gen 3 sprites still fail: `firered-leafgreen/shiny/212.png` and `icons/149.png`. jsDelivr answers 403 "Package size exceeded the configured limit of 50 MB", the files exist on raw GitHub, and `@master` fails the same way, so no newer SHA passes. That is a follow-up ticket, not a mapping defect.

Excluded: Gen 2 indices 116 and 221 (PokeAPI lists two items each and Gen 2 has no item names to choose), items with no art, and any committed icon file.
